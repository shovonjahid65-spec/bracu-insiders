# BRACU Insiders

Your Campus. Your Community. Your Updates.

An independent student newsroom for the BRAC University community. The public website, editorial dashboard and private inbox are one Java 21 Spring Boot application backed by PostgreSQL. The interface uses server-rendered Thymeleaf HTML, custom CSS and a small JavaScript file. The supplied Facebook page is linked from the header, contact page and footer.

## Windows-এ প্রথমবার চালু করুন

1. ZIP ফাইলটি **Extract All** করুন। Docker Desktop খুলে Linux containers চালু হওয়া পর্যন্ত অপেক্ষা করুন।
2. যে ফোল্ডারে `start.ps1` আছে, সেখানে PowerShell খুলুন। চালান `.\start.ps1`। প্রথমবার Docker প্রয়োজনীয় ইমেজ ও Java dependencies ডাউনলোড করবে।
3. চালু হলে ব্রাউজারে **http://localhost:8080** খুলুন। অ্যাডমিন ড্যাশবোর্ডের ঠিকানা **http://localhost:8080/admin**।
4. প্রথমবার স্ক্রিপ্টটি একই ফোল্ডারে `.env` বানায়। সেখানে `ADMIN_USERNAME` এবং `ADMIN_PASSWORD`-এর মান দিয়ে সাইন ইন করুন। এই ফাইলটি ব্যক্তিগত রাখুন।
5. প্রথম পোস্ট দিতে **Posts → New post** খুলুন। লেখা, ক্যাটাগরি ও ছবি যোগ করে **Save draft** অথবা **Publish** চাপুন। **Pin as a featured story** নির্বাচন করলে প্রকাশিত পোস্টটি হোমপেজের প্রধান খবর হতে পারে।

PowerShell-এ স্ক্রিপ্ট চালানোর অনুমতি সীমিত থাকলে নিচের manual Compose পদ্ধতিতেও চালু করা যায়। কম্পিউটারে চালানো ঠিকানাটি শুধু স্থানীয় ব্যবহারের জন্য। সবাইকে ওয়েবসাইটটি দেখাতে একটি Java বা Docker হোস্ট ও PostgreSQL ডেটাবেস লাগবে।

## Quick start on macOS or Linux

Start Docker with a current Compose v2 plugin and run the following in the extracted project folder. The first run also uses OpenSSL to generate random local credentials.

```bash
bash start.sh
```

Open the address printed by the launcher. To stop the services, run `docker compose down`. Run the launcher again to start them. The named PostgreSQL volume retains posts, accounts, uploaded files and correspondence. Preserve the volume when stopping or upgrading.

### Manual Compose setup

1. Copy `.env.example` to `.env`. Set three distinct random secrets for `DB_ADMIN_PASSWORD`, `DB_PASSWORD` and `ADMIN_PASSWORD`. The first editor password must be at least 14 characters and at most 72 UTF-8 bytes. Passwords generated by the launchers meet this requirement.
2. Run `docker compose up --build -d --wait`. The project builds from the editable source. Set `HTTP_PORT` in `.env` to choose another local port.
3. Use `docker compose logs app db` for startup diagnostics. Database bootstrap variables apply on the first initialization of a volume.
4. First startup can load eight editable starter posts with source links, campus photography, the original and updated rover artwork, and the ten-second reveal video. To begin with an empty newsroom, set `SEED_EDITION=false` **before the first launch**. Subsequent starts preserve editorial changes and deletions.

## Publishing and messaging

| Task | How to do it |
| --- | --- |
| Publish a post | In **Posts → New post**, enter a title and caption, choose a category, and optionally add article text, a source, a video and images. The first or selected cover appears on the feed. |
| Upload images | Select multiple JPEG or PNG files in the editor, or upload them in **Media** first. Each post supports up to six images. Each image can be up to 4 MB and 12 megapixels. Edit alternative text under **Media**. |
| Add video | Paste a YouTube or Vimeo URL to embed it. Other HTTPS video links open the original. The supplied MP4 plays locally in its own post. |
| Update a live story | Open **Posts → Edit** and select **Publish** after editing. The existing public URL stays the same. **Save draft** or **Unpublish** removes it from public listings and its public details route. |
| Choose the lead | Pin a published post. If several are pinned, the most recently published one leads. With none pinned, the newest published story leads. |
| Add an event or announcement | Enter an event’s first day, optional last day, time or location. Dated posts appear in the calendar until the last day. Categories marked **Campus wire** provide the homepage announcement. |
| Manage sections | **Categories** controls the display name and the section used by Campus Updates or Student Stories. Move existing posts before deleting their category. |
| Read and answer messages | Open **Messages**, select a thread and choose **Send private reply**. Archive, restore or delete the thread from this screen. Deleting a thread also deletes its attachment and replies. |
| Check a reply as a visitor | Save the receipt code shown after submission and enter it at `/replies`. This works without an email address or account. Replies are delivered through the receipt page. |
| Change contact details | **Settings** edits the publication name, tagline, newsroom email and Facebook URL. |

The homepage’s popular list uses actual story opens, with repeat visits to recently opened stories counted once per session. Publication times and the calendar use Asia/Dhaka.

## Run the included Java application without Docker

Create a PostgreSQL 16 database and give an application login ownership of that database or its target schema. The login needs permission to apply Flyway migrations. Install Java 21 and supply the environment variables below using your operating system or hosting provider’s secret settings. A standalone JAR reads process environment variables. The `.env` file is loaded by Docker Compose.

| Variable | Value or purpose |
| --- | --- |
| `DB_URL` | JDBC connection string, for example `jdbc:postgresql://localhost:5432/insiders` |
| `DB_USER`, `DB_PASSWORD` | PostgreSQL application login and password |
| `ADMIN_USERNAME`, `ADMIN_PASSWORD` | First editor credentials on an empty database. Use 3–80 username characters from letters, numbers, period, underscore, @, + or hyphen. |
| `PORT` | Java HTTP port, default 8080 |
| `COOKIE_SECURE` | Set to `true` behind production HTTPS. Use `false` on local HTTP. |
| `SEED_EDITION` | Set to `true` or `false` for the first startup |
| `FORWARDED_HEADERS`, `TRUSTED_PROXY_REGEX` | Configure only for a trusted reverse proxy. See the deployment guide. |

```bash
java -jar release/bracu-insiders.jar
```

If you edit source files, build a new JAR with a full JDK 21 and Maven 3.9 or later.

```bash
mvn clean package
java -jar target/bracu-insiders-1.0.0.jar
```

## Project structure

| Path | Contents |
| --- | --- |
| `src/main/java/bd/bracuinsiders/web/` | Public MVC pages, admin controllers, form binding, published-only REST endpoints and file delivery |
| `src/main/java/bd/bracuinsiders/service/` | Publishing, editorial queries, upload validation, inbox and reply logic, abuse prevention and activity logging |
| `src/main/java/bd/bracuinsiders/repository/` | Spring Data JPA repositories |
| `src/main/java/bd/bracuinsiders/model/` | Persistent entities and navigation sections |
| `src/main/java/bd/bracuinsiders/config/` | Spring Security, first-run initialization and interactive editor provisioning |
| `src/main/resources/templates/` | Public pages, admin screens and reusable HTML fragments |
| `src/main/resources/static/` | Separate CSS, JavaScript, fonts, images, video and captions |
| `src/main/resources/db/migration/` | Versioned PostgreSQL schema, default categories and settings |
| `src/main/resources/edition/` | Opening-edition content and media metadata |
| `src/test/java/` | Integration tests exercising the actual Spring and PostgreSQL stack |
| `db-init/` | Fresh Compose database role setup |
| `release/` | Prebuilt executable JAR |
| `docs/` | Deployment, database design and editing guides |
